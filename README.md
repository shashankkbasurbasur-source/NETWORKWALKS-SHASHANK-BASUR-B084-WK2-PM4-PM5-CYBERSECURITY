# Week 2 – Cybersecurity Internship

**Networkwalks | Cybersecurity Internship**

## Project Overview

This repository documents my Week 2 practical activities, focusing on OSINT-based footprinting and local network discovery.

## Modules Completed

### 1. W2-PM4 – TheHarvester

Used TheHarvester to collect publicly available domain-related information from multiple OSINT sources.

Activities:
- Domain information gathering using the Baidu source.
- Enumeration using all available configured sources.
- Review and documentation of collected results.

### 2. W2-PM5 – Zenmap Network Scanning

Used Zenmap, the graphical interface for Nmap, to perform local network discovery.

Activities:
- Identified the local network range.
- Performed host discovery.
- Reviewed discovered hosts and available network information.
- Generated a network topology diagram.

## Tools Used

- Kali Linux
- TheHarvester
- Zenmap
- Nmap

## Key Learning Outcomes

- Understanding OSINT-based information gathering.
- Working with multiple information sources.
- Understanding local network discovery and host identification.
- Interpreting scan results and documenting technical observations.
- Recognising the importance of authorised security testing.

## Disclaimer

These activities were conducted for educational purposes within the assigned internship scope. Sensitive information and identifying network details have been excluded from this public repository.
